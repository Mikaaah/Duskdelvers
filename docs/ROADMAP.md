# Duskdelvers roadmap

## 0.4.0 — Natural Cavern Overhaul
- [x] Remove all authored starter structures, corridors, room waves and boss vaults.
- [x] Keep existing enormous Nether-derived cave density function unchanged.
- [x] Create 16 cave-specific Duskdelvers biomes and 5 biome danger levels.
- [x] Scale climate noise to make biome patches considerably smaller.
- [x] Twilight Forest and Aether inspired cave biomes with optional registered natural block accents.
- [x] Natural worldgen cache barrels and five difficulty-based loot tables.
- [x] Vanilla biome mobs, natural caves, optional ambient modded creatures and biome-sensitive difficulty.
- [x] Keep shared group exploration, per-player daily entries, timed trips, inventory-on-death and portal mechanics.
- [x] Replace boss completion with once-per-run natural-cache discovery milestone.
- [ ] Client screenshots, full TNK3 multi-mod compatibility and rare cache encounter statistics.

## Next — Biome depth
- More vegetation families, naturally flowing cave streams, giant mushrooms and Aether/Twilight-specific vegetation variants.
- Ambient fog and particles, unique creature/ecology by biome, biome-specific material finds.
- Natural treasure types beyond barrels, including fossils and mineral veins.
- Configurable biome patch size and cache rarity.
- Improved team discovery journal, maps and iconography, better expedition UI.
- Optional combat/event hooks validated against Epic Fight, Cataclysm, Iron's Spells, and TNK Loot.
- Safe old-region cleanup after explicit confirmation, never forced automatic deletion.
